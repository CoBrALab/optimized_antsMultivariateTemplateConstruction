# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Re-implementation of the ANTs `antsMultivariateTemplateConstruction2.sh` template construction pipeline for neuroimaging. Builds unbiased average templates from populations of images (MRI, PET, etc.) through iterative registration and averaging, then supports deformation-based morphometry (DBM) and spatial resampling of labels/maps.

## Architecture

### Script Hierarchy

**Core pipeline** (single-level):
- `modelbuild.sh` - Main template construction pipeline. Iterates: register all inputs to target, average, sharpen, shape-update. Produces `output/final/average/template_sharpen_shapeupdate.nii.gz`.
- `dbm.sh` - Post-processing: computes Jacobian determinants from modelbuild transforms for voxel-wise morphometry.
- `commonspace_resample.sh` - Resample labels/maps from subject space into template space.
- `subjectspace_resample.sh` - Resample labels/maps from template space into subject space.

**Two-level wrappers** (longitudinal):
- `twolevel_modelbuild.sh` - Wraps `modelbuild.sh` for longitudinal data (within-subject then between-subject).
- `twolevel_dbm.sh`, `twolevel_commonspace_resample.sh`, `twolevel_subjectspace_resample.sh` - Corresponding two-level post-processing.

**Shared infrastructure:**
- `helpers.sh` - Logging (b3bp-style), error handling/traps, `preflight_check()`, `run_smart()`, `extension_strip()`. Sourced by all main scripts. Sets `__dir` to repo root and adds `antsRegistration_affine_SyN/` to PATH.

**Python utilities** (called by bash scripts, require SimpleITK/NumPy/SciPy/VTK):
- `sitk_image_math.py` - Image averaging with advanced methods (trimmed_mean, efficient_trimean, huber, welford online stats).
- `sitk_average_affine_transforms.py` - Affine transform averaging via Lie algebra (matrix log/exp decomposition).
- `interp_transform.py` - Affine transform scaling via VTK interpolation between identity and input transform.
- `sitk_invert_scale_warp_field.py` - Warp field inversion and scaling.

**Git submodule:**
- `antsRegistration_affine_SyN/` - Registration wrapper providing optimized scale pyramids and constrained linear transform paths (rigid->similarity->affine).

### Argument Parsing with Argbash

All bash scripts use [Argbash](https://argbash.dev) for argument parsing. The argument definitions are `# ARG_*` comment lines at the top of each script (the "preamble"). Argbash then generates the parsing code between the `### START OF CODE GENERATED BY Argbash` and `### END OF CODE GENERATED BY Argbash` markers.

**After editing any `# ARG_*` preamble lines, you must regenerate the parsing code:**
```bash
argbash -i <script.sh>
```
The `-i` flag edits in-place. Only the generated block changes; user code outside the markers is preserved.

Do not manually edit code inside the generated Argbash block.

### Job Execution Model

All computational work is written to job files in `${output_dir}/jobs/${datetime}/` and submitted via [qbatch](https://github.com/CoBrALab/qbatch), which handles local parallel execution or cluster submission (SGE/PBS/SLURM). Scripts build the complete work graph as text files of commands, then submit them with dependency chains. File-presence-based state tracking (`[[ ! -s output_file ]]` guards via `run_smart()`) enables pipeline resume.

### Pipeline Flow (modelbuild.sh)

1. **Initial target**: Create or copy starting target (`dumb` average, `com` center-of-mass alignment, `first` input, or external file).
2. **Stage loop**: Iterate over stages (rigid, similarity, affine, nlin, volgenmodel-nlin) with configurable iterations per stage.
3. **Per-iteration**: Register all inputs to current target -> average resampled images -> sharpen -> average transforms -> shape update (apply inverse average transforms to sharpened average).
4. **Final target** (optional): Register the unbiased average to an external target for downstream alignment.

### Variable Naming Convention

Argbash-generated variables follow `_arg_<option_name>` with hyphens converted to underscores (e.g., `--gradient-step` becomes `_arg_gradient_step`, `--dry-run` becomes `_arg_dry_run`). Boolean options use `"on"`/`"off"` string values.

## External Dependencies

- **ANTs** (AverageImages, ImageMath, antsRegistration, antsApplyTransforms, CreateJacobianDeterminantImage, etc.)
- **qbatch** - Job submission and parallelism
- **GNU parallel** - Local command parallelism
- **Python 3** with SimpleITK, NumPy, SciPy (for advanced averaging) and VTK (for `--scale-affines`)

## Testing

```bash
# Check affine convergence (mean determinant should approach 1):
bash testing/test_affine_convergence.sh <output_dir>
```

There is no automated test suite. Validation is done by running the pipeline on test data and inspecting outputs.
